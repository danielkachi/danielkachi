# Welcome to My Code Space 👨‍💻

I’m Daniel Henry, a Flutter and full-stack software engineer focused on building production mobile products and the systems behind them.

My work spans mobile engineering, backend APIs, real-time features, product architecture, performance optimisation, and production deployment across iOS and Android.
